# Insights

Dati che Manuel manda (screenshot o esportazioni di YouTube Studio e Instagram) e analisi.

- Un file per video pubblicato: `analisi/<video>.md` con data, numeri chiave (visualizzazioni, fidelizzazione
  media e curva, CTR delle impressioni, iscritti ottenuti; per IG copertura, salvataggi, condivisioni), cosa ha
  funzionato, cosa no, ipotesi.
- `analisi/lezioni.md`: lezioni confermate da più video. Quando una lezione è confermata, diventa una regola nel
  file dell'area (`regole/montaggio_documentario.md`, `regole/copy.md`, `regole/pianificazione.md`).
- Da rivalutare dopo 6-8 lunghi: lingua (solo italiano o anche inglese), durata, giorno di uscita.
